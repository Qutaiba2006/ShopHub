# Shop Hub

Shop Hub is an interactive e-commerce website developed using HTML5, CSS3, Bootstrap 5, and JavaScript.

The project focuses on building a user-friendly shopping interface with dynamic product displays, shopping cart functionality, and responsive design.

## Features

- **Product Catalog:** Displays products from different categories, including smartphones, laptops, tablets, and mobile accessories.
- **Shopping Cart:** Allows users to add products to their cart and manage selected items.
- **Product Search:** Helps users find products.
- **Dark & Light Mode:** Provides different visual themes.
- **Dynamic Content:** Uses JavaScript to update product displays and shopping cart information.
- **Responsive Design:** Adapts to different screen sizes using Bootstrap 5.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Git & GitHub

## How to Run

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Explore the products and shopping cart.

An internet connection is required to load external resources and product information.

## Project Purpose

This project was developed to improve my practical skills in JavaScript, DOM manipulation, responsive web design, and interactive user interfaces.
